## Derived BSX export

`derived/bsx-keyboard-defect` is generated by
`python scripts/prepare_keyboard_datasets.py --skip-keycap`.
It retains 429 unique images, clamps 10 out-of-bound VOC boxes, preserves negative
images as empty YOLO label files, and uses a deterministic 300/64/65 train/val/test
split. The original raw files are never modified.

The only learned class is `keyboard_defect`. The raw spelling
`dameged-keys` is mapped to it. This evidence must **not** be reported as accuracy
for `missing_key`, `shifted_key`, or `tilted_key`.

## Required manual confirmations

1. Product scope: **mixed** (laptop and external keyboards). This is consistent
   with the available sources but implies domain shift must be reported.
2. Provenance URLs:
   - Kaggle Key Detection: https://www.kaggle.com/datasets/farmermatzle/keyboard-key-detection
   - Roboflow BSX: https://universe.roboflow.com/bsx-xprrg/keyboard-defect-detection-e8dcz
   - Roboflow RSI: https://universe.roboflow.com/rsi-fcy8m/keyboard-defect-detection

## Limits

The network data supplies no verified per-class labels for shifted or tilted keys.
Specific geometry labels in the application are experimental OpenCV heuristics;
only generic binary keyboard-defect evaluation is supported by BSX.
